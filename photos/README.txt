The photos and videos now live in the "media" folder (one subfolder per stop),
already converted for the web: phone-friendly JPGs, full-size JPGs for downloading,
and MP4 videos that play in every browser. Location data was removed from the photos.

To change the media: put the original files in ../journey-media-originals named like
amalfi-1.HEIC, bc4.MOV, tor1.JPG, zion2.JPG, gua3.JPG, sav1.MOV, van12.JPG
then run  python3 media.py  and  python3 build.py  inside journey-src.
